# 🤖 AI Terminology Explorer - Streamlit Edition

A beautiful, interactive web application for exploring AI terminology, built with Streamlit.

## ✨ Features

- 📚 **17 AI Terms** — Comprehensive coverage from LLMs to Context Evaluation
- 🔍 **Live Search** — Find terms by name or content instantly
- 📂 **Category Filtering** — Browse by topic categories
- ⌨️ **Keyboard Shortcuts** — Quick navigation with number keys
- 📊 **Statistics Dashboard** — See term counts and categories at a glance
- 🎨 **Modern Dark UI** — Easy on the eyes with a sleek design
- 📱 **Fully Responsive** — Works on desktop, tablet, and mobile
- 🔗 **Related Terms** — Discover connected concepts
