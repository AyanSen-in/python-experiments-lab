# 🔊 Text to Speech Converter

A simple Python project that converts user-entered text into speech and saves the generated audio as an MP3 file.

This project uses the **gTTS (Google Text-to-Speech)** library to convert text into natural-sounding speech.

---

## 🚀 Features

- ✍️ Accepts text input from the user
- 🔊 Converts text into speech
- 🌐 Supports English language
- 💾 Saves the generated speech as an MP3 file
- 🐍 Simple and beginner-friendly Python project

---

## 🛠️ Technologies Used

- Python
- gTTS (Google Text-to-Speech)
