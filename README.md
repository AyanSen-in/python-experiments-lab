# 🏆 Kaun Banega Crorepati — Python Quiz Game

A simple **Kaun Banega Crorepati (KBC)-inspired quiz game** built using Python.

The game presents multiple-choice questions to the player, similar to the popular quiz show. Players answer questions to increase their virtual prize money, while an incorrect answer ends the game.

## 🎮 Features

* Multiple-choice quiz questions
* Progressive prize money
* Instant answer verification
* Score tracking
* Game-over system
* Simple and beginner-friendly Python code
* Console-based interface

## 🛠️ Technologies Used

* **Python**
* Conditional statements
* Loops
* Lists / Dictionaries
* Functions
* Basic input and output

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run:

```bash
python KBC.py
```

4. Follow the instructions displayed in the terminal and start playing!
