# 🎨 Pixel Art & Shape Studio

An interactive visual canvas built using Python's `turtle` and `tkinter` graphic engines for drawing pixel art, geometric polygons, and complex curves.

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## ✨ Features

- **Geometric Shapes**: Draw squares, circles, triangles, diamonds, stars, spirals, polygons, and hearts.
- **Custom Color Palettes**: Integrated Tkinter GUI color picker for custom stroke, fill, and canvas backgrounds.
- **Adjustable Dimensions**: Configure sizing and side counts on the fly.
- **Zero External Dependencies**: Standard library only (`turtle`, `tkinter`).

## 🚀 Quick Start

```bash
python main.py
```
