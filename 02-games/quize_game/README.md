# 🎯 Python Quiz Game

A simple and interactive **Quiz Game built with Python**. The game presents questions to the user, accepts their answers, checks whether the answers are correct, and calculates the final score.

This project is beginner-friendly and demonstrates fundamental Python programming concepts.

---

## 📌 Features

* 📝 Multiple quiz questions
* 🎮 Interactive command-line gameplay
* ✅ Answer validation
* 📊 Score calculation
* 🔄 Simple and easy-to-understand logic
* 🐍 Built entirely with Python

## 🎮 How the Game Works

1. The game starts and displays a question.
2. The user enters an answer.
3. The program checks whether the answer is correct.
4. The user's score is updated.
5. More questions are displayed.
6. At the end, the final score is shown.
