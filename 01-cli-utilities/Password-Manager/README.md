# 🔐 Password Manager CLI

A lightweight personal password manager featuring local file persistence and an interactive password generator.

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## ✨ Features

- **Store & View**: Save account credentials and view them in a clean formatted CLI table.
- **Search Capabilities**: Find stored logins quickly by keyword.
- **Built-in Generator**: Create strong random passwords using configurable character lengths with alphanumeric and symbolic complexity.
- **Local Persistence**: Stores credentials in a structured local file (`passwords.txt`).
- **Zero External Dependencies**: Pure Python standard library (`random`, `string`, `pathlib`).

## 🚀 Quick Start

```bash
python main.py
```
